# Holberton School - Softy Pinko Docker Project

This repository contains the solutions for the **holbertonschool-softy-pinko-docker** project at Holberton School. The project focuses on containerizing an application using Docker, allowing it to run consistently across different environments by packaging the application and its dependencies into a container.

## 📝 Project Overview

**Docker** is a powerful tool for creating, deploying, and managing containers. This project covers the basics of using Docker to build, manage, and deploy an application within a Docker container. By the end of the project, you will have a better understanding of how to use Docker to package applications in a way that ensures they run reliably in any environment.

### Key Concepts:
- **Docker**: A platform for developing, shipping, and running applications inside containers.
- **Docker Images**: Read-only templates used to create containers, including the application and all its dependencies.
- **Docker Containers**: Lightweight, standalone, and executable packages of software that include everything needed to run the application.
- **Dockerfile**: A script containing instructions on how to build a Docker image.
- **Docker Compose**: A tool to define and run multi-container Docker applications using a YAML file.

### Skills Gained:
- Writing a `Dockerfile` to containerize an application.
- Building and running Docker images.
- Managing containers using Docker commands.
- Using Docker Compose to orchestrate multiple containers for an application.
